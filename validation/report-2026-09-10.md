# Cognitive Trails 5.1.1 — code review and regression verification

September 10, 2026. Review base: `341cde7` on main. Implementation: `ddb60d0`. This pass uses synthetic fixtures and disposable Chrome profiles. No installed user browsing data was read or changed.

## Findings and fixes

| Finding | Reproduction and resulting behavior |
| --- | --- |
| Estimated gaps could displace observed interaction | A later background visit reduced five minutes of timestamped activity on another tab to one minute. Timestamped intervals now take precedence over legacy interaction totals, then history estimates. Overlaps still count once; ties within the same evidence type use recency and stable IDs. Startup repair version 3 updates stored totals without deleting visits. |
| Continuity and map links crossed capture pauses | A pause shorter than 30 minutes did not break the sequence. Pauses now break transitions. Simultaneous visits, including their ambiguous predecessors/successors, cannot establish an ordered connection. The evidence drawer documents these exclusions. |
| Interrupted pauses left sessions active | If the worker stopped after persisting pause but before ending the session, untimed sessions could remain active indefinitely. Recovery now uses the first overlapping persisted pause boundary, including pauses that have since ended. Timed sessions retain the earlier of that boundary and their deadline. |
| Browser cleanup failures left stale session state | Alarm-clear or notification-clear failures could leave an alarm, show a suppressed notification on retry, or leave a seen recap's notification visible. Completion/suppression are persisted before external calls; cleanup retries with durable markers. |
| Offscreen cleanup could silently drop a new run | The worker could report a start while the offscreen host was still busy unloading models and ignored the request. The host now explicitly accepts/refuses work, reports completion after unload attempts, and closes even if the completion reply is lost. |
| Map render test depended on local clock time | Today's noon visits were in the future during a morning test run. Fixed-clock fixtures now exercise both populated and morning views. |

## New regression coverage

- `evidenceBoundaries.test.js`: measured-versus-estimated precedence; pause and simultaneous-timestamp boundaries; Map and recap consistency; 100 seeded allocation cases checked against a separate per-tick oracle and reversed input order.
- `sessionRecovery.test.js`: open/closed pauses across restart, pause/deadline ordering, alarm failure, suppressed notifications, seen-recap cleanup, and repeated completion.
- `offscreenLifecycle.test.js`: explicit admission, refusal during cleanup, cleanup ordering, independent unload failures, and a missing worker reply.
- Expanded existing suites: five concurrent worker session starts; malformed and overlapping capture intervals; late captures from closed pauses; hidden-tab gaps; back/forward cache restoration; 31 minutes of continuously observed interaction; idempotent repair from version 2 to 3; deterministic map rendering.
- Expanded actual extension tests: restart after a partially persisted pause, using real IndexedDB and service-worker shutdown.

## Remaining evaluation

Passing tests establish the exercised behavior, not scientific validity or flawless grouping. Time remains approximate and silent reading can be missed. Mixed-page classification quality, retrieval usefulness and correction frequency still need an independent user pilot. Battery effects, smaller-memory/non-Apple laptops, and years of history remain unmeasured by this pass. The installed extension was not reloaded during this review; reload it after updating to use 5.1.1.
