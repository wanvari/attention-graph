# Cognitive Trails 5.1 — verification record

September 7, 2026. Apple M3 Pro, 18 GiB unified memory. This report separates synthetic runtime checks from a specific installed-data bug investigation. It does not validate cognition, intention or model label quality.

## Product and evidence

Home exposes estimated time, Continuity, Top trail and Return share with literal denominators, comparison eligibility, formulas and contributing records. Comparisons use up to 28 prior calendar days through the same local clock time; a minimum of seven eligible days is required. Optional timed/untimed sessions persist through worker restart and show factual time recaps. Session actions do not invoke a model.

Home, Map, Audit and recaps allocate the same non-overlapping intervals. Timestamped activity is clipped to the requested period; legacy totals retain estimated placement. Operational pages without interaction timing have unknown duration rather than a history-gap time estimate. Repetition alone cannot automatically group them. Corrections are durable and have priority over later model commits. Map lines require at least two observed sequences, with actual page examples.

A private read-only copy of the installed schema-4 database reproduced the reported Claude Status error: stored history gaps summed to approximately 805 minutes, despite only 35 seconds of captured interaction. The corrected record and atomic repair both retain the 35 seconds, remove its automatic membership and preserve original navigation entries. Background refresh is a plausible source of repeated entries; the records do not establish visible time. No personal browsing rows, titles or timestamps are included in committed fixtures. The installed extension was subsequently reloaded to 5.1.0. Live schema-5 diagnostics and the normal Home evidence drawer independently confirm 35 seconds, preserved navigation entries, no automatic membership, and explicit unknown-duration labels.

## Synthetic laptop run

The cold-vector-cache, 28-day fixture imported 410 visits and 224 eligible page aggregates. The production profile used bge-m3:latest and qwen3:4b, sequential calls, 50% pacing, four CPU threads, 8,192 context tokens and 1,800 output tokens.

- Pass 1: 91.115 seconds; 100 pages embedded; 88 pending.
- Pass 2: 47.023 seconds; 82 pages embedded and six cached vectors reused; zero pending.
- Total: 138.138 seconds across two bounded passes, including 68.144 seconds of pacing.
- Peak sampled Ollama residency: approximately 3.59 GiB. No simultaneous residency of both configured models was observed.
- Record construction: 6.5 ms, excluding IndexedDB reads and DOM work.

Full current transcripts, vectors and metadata are in fixtures/current. Raw measurements are in laptop-2026-09-07.json. Samples from Ollama are not continuous measurements of system memory, battery use or GPU utilization. An independent 20,000-visit/1,000-page/100-trail computation check took 293 ms to construct the record and 133 ms for daily signals; it excludes storage and rendering. See dashboard-2026-09-07.json.

Of 200 clear-topic fixture pages, 171 received memberships. Ten of 24 ambiguous/junk pages were also grouped. Among 1,323 within-trail page pairs, 1,298 shared the same clear ground-truth topic (98.11% pair precision). Read this together with coverage and the noise assignments: sparse subjects can remain ungrouped, while mixed link roundups remain a weakness. These results do not establish human label quality or real-world retrieval success.

## Checks and remaining evaluation

The full unit/protocol/migration/DOM suite passes 33 test files, including exact current-profile transcript replay, interval overlap, operational refresh, manual corrections, schema-4 diagnostics and upgrade recovery, local-calendar/DST comparisons, sessions and notification retry. Real Chrome capture/privacy checks pass. Product E2E covers evidence drawers and focus return, correction/reassignment, optional sessions, reload/restart, delayed alarms, pause, recap links, metadata export, Audit and deletion cleanup. The pipeline E2E uses live local inference and verifies offscreen shutdown, abandoned-run recovery and duplicate-run rejection; all four live pipeline checks pass.

Light, dark and 390-pixel layouts were inspected. A mobile trail-card overflow was corrected. Rings retain labels and percentages independently of color. Reduced-motion preferences are respected. The release archive contains only allowed runtime assets and the synthetic sample; private diagnostics and development dependencies are excluded.

The next pilot should measure whether users find and resume useful pages, correction frequency, mixed-page grouping errors, missed/unknown time, long-history browser load time, battery effects and smaller-memory/non-Apple hardware. This release is suitable for local testing; Chrome Web Store publication, multi-device sync and independent human evaluation remain outside this implementation.
